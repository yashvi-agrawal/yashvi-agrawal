## Projects

### 🎮 Pixel Party

**Interactive Tabletop Game | C, C++, STM32, Raspberry Pi, Custom PCB**

Pixel Party is an interactive multiplayer tabletop game that combines **embedded hardware** with a graphical interface running on a Raspberry Pi.

Our team of four designed and fabricated a **custom PCB centered around an STM32 microcontroller**, which served as the primary interface for the game's physical inputs. The board interfaces with joysticks, buttons, break-beam sensors, and other peripherals, while a Raspberry Pi handles the game logic and graphical interface.

**Key technologies:**
- Embedded C
- STM32F411RE
- Custom PCB Design & Fabrication
- ADC, GPIO, UART, USB HID
- Raspberry Pi
- Godot / Raylib
- Hardware-software integration

🔗 **[View the Pixel Party Repository](https://github.com/GeorgiaGriffin/pixel-party)**

### 🖥️ RISC-V Processor

**Processor Design | SystemVerilog, RISC-V, FPGA**

I designed and implemented a **RISC-V processor** as part of my processor prototyping coursework at Purdue. The project explored both **single-cycle and pipelined processor architectures**, including datapath design, control logic, instruction execution, and performance analysis.

I also investigated the effects of **memory latency and caching on processor performance** and evaluated the resulting designs using FPGA synthesis and timing analysis.

**Key concepts:**
- RISC-V ISA
- SystemVerilog / RTL Design
- Single-Cycle Processor
- Pipelined Processor
- Datapath & Control Logic
- FPGA Design
- Timing Analysis
- Cache & Memory Performance

> **Note:** The source repository for this project is not publicly available, but I am happy to discuss the architecture and implementation in more detail.
